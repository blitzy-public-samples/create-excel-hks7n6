# Backend dependency manifest - Excel Clone API (FastAPI).
#
# Runtime: Python 3.9 (infrastructure/docker/Dockerfile.backend, FROM python:3.9-slim).
# Every entry is an exact pin, resolved and installed together on CPython 3.9.25 with no
# resolver conflict. Rationale for each pin is recorded in
# documentation/Security Decision Log.md; this file records the pins and the facts only.
#
# INTERPRETER FLOOR: CPython 3.9.2 or newer. The 3.9 series alone is not sufficient -
# cryptography 50.0.0 declares Requires-Python ">=3.9, !=3.9.0, !=3.9.1", so this set is
# not installable on 3.9.0 or 3.9.1. python:3.9-slim currently ships 3.9.25 and satisfies
# it; a base image pinned to an earlier 3.9 patch would fail to resolve.
#
# This manifest is fully resolved: it exact-pins the COMPLETE dependency graph - the 24
# direct requirements below and the 65 packages they pull in transitively - so a build
# installs one known set of versions rather than re-resolving the graph afresh. Entries
# carrying an environment marker are the five packages whose presence depends on the
# platform or the interpreter implementation; the resolution was cross-checked on linux,
# windows and macos at Python 3.9.25 and produced identical versions for every other
# package.
#
# Reproducibility gap that remains: versions are pinned, artifact hashes are not, so this
# file pins versions but does not pin file contents. pip's --require-hashes mode needs a
# hash on every entry, and generating one per distribution for every supported platform is
# a separate task tracked in SECURITY.md.
#
# ADVISORY POSITION: pinning clears no outstanding advisory. It closes the reproducibility
# weakness CWE-1104 / OWASP A06:2021 and holds python-jose above the CVE-2024-33663 fix
# boundary. It does not clear the advisories that the Python 3.9 runtime keeps unreachable,
# because every published fix version for them requires Python 3.10 or newer, and ecdsa
# PYSEC-2026-1325 has no published fix at all. See Decision Log D19 and SECURITY.md.
# The advisory a dependency scan reports on this set beyond that documented baseline is:
#
#   h2 4.3.0 - GHSA-6hr6-w5qg-qmwg. Fix versions 4.4.0 and 4.4.1 both require
#   Python >= 3.10, so it is unreachable here. h2 is not optional: firebase-admin 7.5.0
#   declares httpx[http2]==0.28.1 with no environment marker, and httpx declares
#   "h2<5,>=3; extra == 'http2'", so the h2, hpack and hyperframe pins below are required
#   for a fully-resolved manifest rather than removable. Any dependency-scanning gate
#   added later must carry GHSA-6hr6-w5qg-qmwg in its ignore baseline alongside the
#   runtime-blocked entries, or it fails on its first run and every run after.
#
# The advisory position of this dependency set is recorded in
# documentation/Security Decision Log.md and SECURITY.md.
